## Dataset Structure
DSAII-HR dataset serves as a performance evaluation dataset for industrial anomaly detection and segmentation task. These high-reflective images are filmed by NTU [BioRoLa](http://biorola.me.ntu.edu.tw/). Each faucet instance (instance1\~instance8) contains two folder, `original` and `synthetic`. 

For the `original` folder, it consist of 156 images, with the different filming angles of the same instance. Note that images with the same ids shares the same angle from class to class. (the image `DSAII-HR/instance1/original/image/001.png` shares the same filming angle with `DSAII-HR/instance2/original/image/001.png`) Besides, the folder contains real defects in some images, and are annotated using bounding box record in `mask` folder. (`DSAII-HR/instance1/original/mask/056.png` implies `DSAII-HR/instance1/original/image/056.png` is defective)

For the `synthetic` folder, we apply Stable Diffusion for defect inpainting for each images in `original` folder. The inpainting mask is acquired by random sampling ground_truth mask from [MVTec AD](https://www.mvtec.com/company/research/datasets/mvtec-ad) dataset, then applying augmentations as our input inpainting masks. The inpainting masks are saved under `mask` directory. The output defect images are saved under `images` directory. The failure cases are eliminated.

## Why use DSAII-HR?
DSAII dataset contains normal images with **large intra-class variation**, while defective images are generated by diffusion model. This setting aims to evaluate the model’s **generalizability**. The model needs to learn the abstract pattern of the object/texture and the its normal appearance to achieve better performance. Besides, we provide a flexible way for creating synthetic anomalies. With any image, you can customize your own dataset, and simply edit prompt for controlling defect types. By Following our [instructions](https://github.com/lessthan41/NTHU-CVLAB-Synthetic-Images), you can customize your own image anomaly detection dataset.

## Limitation
The bounding box annotation might not be precise enough for segmentation task. We're still working on it for further improvment.

## Experiment
We test `DSAII-HR` dataset on [Patchcore](https://github.com/amazon-science/patchcore-inspection) (CVPR, 2022), [RegAD](https://github.com/MediaBrain-SJTU/RegAD) (ECCV Oral, 2022) by angle-aligned training strategy. (Ex: use `001.png` in instance1\~instance8 as a group for training/testing) The performance is record as follow. Performance on `synthetic` data is still in progress.

| Method | Mean Image AUC (%) | Mean Pixel AUC (%)|
|-----|-----|--------|
|Patchcore (10%) | 79.8 |   88.7    |
|RegAD  |87.2    |   83.9  |
